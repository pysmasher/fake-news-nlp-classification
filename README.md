# Fake News Categorization using NLP

## Overview

Built an NLP-based text classification pipeline for fake news detection, covering text preprocessing, feature extraction, classification, sentiment analysis, and topic modeling.

## Workflow

```text
News Dataset
     ↓
Text Preprocessing
     ↓
TF-IDF Feature Extraction
     ↓
Classification
     ↓
Model Evaluation
```

Additional NLP analysis was performed using sentiment analysis and topic modeling.

## Technologies

* Python
* Pandas
* Gensim
* NLTK
* VaderSentiment
* Scikit-Learn
* TF-IDF
* SVM
* Logistic Regression
* LDA / LSI
* NLP
* Text Classification

## Models

* Support Vector Machine (SVM)
* Logistic Regression

## Result

* **SVM Accuracy:** 85%
* **Logistic Regression Accuracy:** 78%

SVM achieved higher classification accuracy on the evaluated dataset.
